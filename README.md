# Fundamentos de Sistemas Ciberfísicos (1º semestre)

Códigos da disciplina Fundamentos de Sistemas Ciberfísicos do 1º semestre de Engenharia de Software (PUCPR).

- `aula01/aula01.c`: primeiro programa em C (soma e média)
- `TDE-final-VagaCerta/`: **VagaCerta**, o TDE final. Detecta vagas de estacionamento livres e ocupadas com sensores ultrassônicos, LEDs e display LCD I2C no Arduino. A simulação está no Tinkercad (link em `Link-tinkercad.txt`).
- `arduino/sketch_apr27a`: display de 7 segmentos (cátodo comum)
- `arduino/sketch_jun22a`: versão de desenvolvimento do VagaCerta
